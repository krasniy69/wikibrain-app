# Wikibrain — десктоп (бета)

Локальная база знаний и трекер задач: заметки как markdown-файлы в папке на вашем компьютере.

## Скачать
Возьмите сборку под вашу ОС на вкладке [Releases](../../releases):
- **macOS** (Apple Silicon) — `.dmg`
- **Windows** — `.msi` / `.exe`
- **Linux** — `.AppImage` / `.deb`

## Первый запуск (сборки не подписаны)
- **macOS**: правый клик по приложению → «Открыть» → «Открыть». Либо: Системные настройки → «Конфиденциальность и безопасность» → «Всё равно открыть».
- **Windows**: SmartScreen → «Подробнее» → «Выполнить в любом случае».
- **Linux**: `chmod +x Wikibrain*.AppImage && ./Wikibrain*.AppImage`

## Обновления
Встроены: приложение само проверяет и ставит новые версии (⌘/Ctrl+K → «Проверить обновления»).

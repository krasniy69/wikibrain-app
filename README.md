# Wikibrain — десктоп (бета)

**Локальная база знаний + трекер задач в одном приложении.** Ваши документы базы знаний — это
обычные **markdown-файлы** в папке на вашем компьютере: ничего не заперто в
проприетарном формате, всё работает офлайн и принадлежит вам.

Вдохновлено Obsidian, с идеями из Notion, Linear и Logseq: вики-связи и граф знаний
объединены со встроенным таск-трекером (Kanban / таблицы / календарь / Гант) и
AI-ассистентом по вашим документам.

> 🧪 **Это бета для тестирования.** Спасибо, что помогаете! Баги, идеи и впечатления —
> в [Issues](../../issues). Чем подробнее (ОС, шаги, скриншот) — тем лучше.

|---|---|
| **macOS** (Apple Silicon, M1/M2/M3) | `.dmg` |

| **Linux** | `.AppImage` или `.deb` |

### Первый запуск (сборки пока не подписаны)
Приложение ещё без платного сертификата издателя, поэтому система перестрахуется —
это нормально для беты:
- **macOS**: правый клик по приложению → **«Открыть»** → **«Открыть»**. Если не вышло —
  Системные настройки → «Конфиденциальность и безопасность» → **«Всё равно открыть»**.
  (Через терминал: `xattr -dr com.apple.quarantine /Applications/Wikibrain.app`)
- **Windows**: SmartScreen → **«Подробнее»** → **«Выполнить в любом случае»**.
- **Linux**: `chmod +x Wikibrain*.AppImage && ./Wikibrain*.AppImage`

### Авто-обновления
Встроены: приложение само проверяет и ставит новые версии.
Проверить вручную — **⌘/Ctrl + K** → «Проверить обновления».

## 🚀 Быстрый старт (5 минут)
1. Запустите приложение → **«Открыть папку (vault)»**. Выберите пустую папку или папку
   с вашими `.md` (можно создать новую — например `Knowledge`).
2. Нажмите **«+»** и создайте пару заметок.
3. В тексте напишите ссылку на другую заметку через двойные скобки: `[[Имя заметки]]`,
   и тег: `#идея`.
4. Откройте **граф знаний** и **поиск** (⌘/Ctrl + K) — посмотрите, как всё связалось.
5. Создайте заметку-задачу (в свойствах выберите тип **task**) и откройте **Доски**.

## ✨ Что попробовать в этой бете (на чём сфокусироваться)
Эта сборка — про **локальную работу** (всё на вашем компьютере). Главное, что стоит
проверить и оценить:

1. **Редактор и markdown** — три режима, рендер таблиц/диаграмм/формул, инлайн-картинки.
2. **Связи знаний** — `[[вики-ссылки]]`, backlinks, граф, переход по ссылкам.
3. **Задачи и доски** — Kanban с перетаскиванием, таблица, календарь, Гант; настройка
   статусов без кода.
4. **Поиск и навигация** — мгновенный поиск, командная палитра, оглавление.
5. **AI-ассистент** — вопросы по вашей базе знаний (нужен свой ключ или локальный
   Ollama — см. ниже).
6. **История версий** — снимки и откат через Git.

Буду особенно благодарны за отзывы: что **непонятно**, чего **не хватает**, что
**тормозит** или **глючит**.

## 🧩 Полный список возможностей

### 📝 Заметки как markdown-файлы
- Хранение в обычной папке (vault): файлы `.md` и `.txt`, читаемые любым редактором.
- **Вики-ссылки** `[[Заметка]]` — с алиасами (`[[Заметка|текст]]`) и ссылками на
  заголовки (`[[Заметка#Раздел]]`).
- **`#теги`** и боковая панель тегов.
- **Backlinks** (кто ссылается сюда) и исходящие ссылки для каждой заметки.
- Автосохранение; **переименование с авто-обновлением всех ссылок** на заметку;
  удаление; создание заметок в один клик.

### ✍️ Редактор с тремя режимами
- **Исходник** — чистый markdown.
- **Live-preview** — подсветка с инлайн-картинками, ссылками и блоками прямо по тексту.
- **Чтение** — полный рендер: таблицы (GFM), **Mermaid**-диаграммы, формулы **KaTeX**
  (`$...$` / `$$...$$`), изображения.
- **Панель инструментов**: заголовки, **жирный/курсив/зачёркнутый/код**, списки,
  чек-листы, цитаты, вставка таблиц, диаграмм, горизонтальной линии и вики-ссылок.
- Изображения: `![[картинка.png]]` и обычный markdown — резолвятся из vault.

### ✅ Задачи и доски (таск-трекер)
- Любая заметка со свойством `type: task` становится **карточкой задачи** с полями:
  статус, исполнитель, срок, приоритет, спринт, дата начала.
- Представления доски:
  - **Kanban** — колонки по статусам, **drag-and-drop** меняет статус.
  - **Таблица** — табличный вид со свойствами.
  - **Календарь** — задачи по срокам, помесячно.
  - **Гант** — таймлайн по датам начала/срока.
- **No-code конструктор статусов** — настраиваете колонки рабочего процесса
  (название, ключ, категория, порядок) без кода.
- **Двусторонняя связь**: задача — это документ, и наоборот (вики-ссылки работают и тут).

### 🔍 Поиск, навигация, граф
- **Полнотекстовый поиск** по всей базе (быстрый, на SQLite FTS5) с подсветкой.
- **Командная палитра** (⌘/Ctrl + K) — мгновенный переход к заметкам и командам.
- **Панель поиска** (⌘/Ctrl + Shift + F).
- **Граф знаний** — визуализация всех связей между заметками.
- **Оглавление** документа с переходом по заголовкам.

### 🤖 AI-ассистент по вашим знаниям
- Задавайте вопросы по своей базе — ответ собирается из релевантных заметок **с
  указанием источников**.
- **Приватность на ваш выбор**:
  - свой ключ **Anthropic / OpenAI / OpenRouter**, или
  - **локально через [Ollama](https://ollama.com)** — данные не покидают компьютер.
- Настраивается в **Настройках** (⌘/Ctrl + ,): провайдер, модель, ключ.
- Ответ ассистента можно **сохранить как заметку**.

### 🕘 История версий (Git)
- Снимки состояния и история изменений каждого документа.
- Просмотр прошлых версий и **восстановление**.
- Синхронизация с удалённым Git-репозиторием (если настроите).

### 🎨 Удобство и приватность
- Темы: **тёмная / светлая / системная**.
- **Local-first**: всё хранится у вас на диске, работает офлайн, без слежки.
- Кросс-платформенность: **macOS, Windows, Linux**.
